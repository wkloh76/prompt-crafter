# Prompt Crafter — 驱动语句集

## 软件开发

> i need something for my team's code review. we use github, PRs are messy, people don't leave good comments. want a checklist or something that reviewers can follow. maybe also for the author before they submit. nothing too long.

> 我们的 PR review 太随便了，经常就是 LGTM 就过了，帮我写个 prompt 让它生成一个 review 规范，reviewer 能照着看，作者提交前也能自查，不要太长。

> make a claude code prompt that helps me write better commit messages. right now i just write "fix" or "update" and it's useless later.

> 我提交信息老是写不清楚，每次都写"fix""update"，过段时间自己都看不懂。帮我写个 Claude Code 能用的 prompt，让它根据 diff 自动生成规范的 commit message。

> write a prompt for a REST API. user registration and login, CRUD for articles, pagination, search. use PostgreSQL.

> 帮我写个 REST API 的 prompt。要有用户注册登录、CRUD 文章、分页、搜索。数据库用 PostgreSQL。

> need a prompt for building a websocket server that handles real-time chat. rooms, typing indicators, online status. use Node.js.

> 我需要一个实时聊天用的 WebSocket 服务端，要支持房间、正在输入提示、在线状态。用 Node.js。帮我写个 prompt。

## 数据分析与洞察

> i have raw user research responses, 200+ entries, very messy. write a prompt that extracts 5-8 core pain points, each backed by a verbatim user quote.

> 我有一份用户调研的原始回答，200 多条，杂乱得很。帮我写个 prompt，让它从中提炼出 5-8 个核心痛点，每条带一句典型用户原话佐证。

> i have quarterly sales reports for the past 3 years. write a prompt that identifies seasonal patterns, growth trends, and anomalies, then summarizes them in an executive-friendly 1-pager.

> 我有过去 3 年的季度销售报告，帮我写个 prompt，让它识别季节性规律、增长趋势和异常数据，汇总成一页管理层能直接看的摘要。

> i have three spreadsheets — sales, inventory, logistics — with inconsistent column names. write a prompt to merge them into one readable business analysis report.

> 三个 Excel，分别是销售、库存、物流数据，列名不统一。帮我写个 prompt，让它合并成一张可读的经营分析报表。

> need a prompt that takes a CSV of customer support tickets and groups them into 5-7 categories, ranking by frequency and average resolution time.

> 有一份客服工单 CSV，帮我写个 prompt，让它把工单归成 5-7 个类别，按出现频次和平均解决时间排序。

## 商业与策略

> i want to build a SaaS tool for indie developers. write a prompt that does a competitive analysis: 3-5 direct competitors, compare pricing, core features, target users, and differentiators.

> 我想做一个面向独立开发者的 SaaS 工具，帮我写个 prompt 让它帮我做竞品分析。列出 3-5 个直接竞品，对比定价、核心功能、目标用户、差异化点。

> write a prompt that generates a one-page business model canvas for a subscription-based mobile app targeting pet owners.

> 帮我写个 prompt，让它为一个面向宠物主人的订阅制移动应用生成一页纸的商业模式画布。

> i'm pitching to investors next week. write a prompt that takes my scattered notes and turns them into a 5-minute elevator pitch outline.

> 下周要跟投资人 pitch，帮我写个 prompt 让它根据我给的零散要点，整理成一个 5 分钟电梯演讲的提纲。

> i need a prompt that drafts a partnership outreach email to a potential integration partner. professional but not stiff, 150 words max.

> 帮我写个 prompt，让它起草一封给潜在集成合作伙伴的合作邀约邮件。专业但不死板，控制在 150 词以内。

## 学习与教育

> i'm learning Rust. write a prompt that designs a 4-week study plan based on my background (5 years of TypeScript), 1 hour per day.

> 我在自学 Rust，帮我写个 prompt 让它根据我的背景（5 年 TypeScript 经验）设计一个 4 周学习计划，每天 1 小时。

> write a prompt that explains monads to a programmer who only knows Python. use analogies, avoid Haskell syntax, and include a concrete code example.

> 帮我写个 prompt，让它向一个只会 Python 的程序员解释什么是 monad。用类比，不要用 Haskell 语法，带一段具体的代码示例。

> i'm giving a team talk on system design. i only have a few keywords and a rough architecture sketch. write a prompt that generates a talk outline plus slide content.

> 我要给团队做一次关于系统设计的分享，手里只有几个关键词和一张架构草图。帮我写个 prompt 让它生成分享大纲 + 幻灯片内容。

> need a prompt that creates a 10-question quiz on HTTP protocols, with increasing difficulty and detailed answer explanations.

> 帮我写个 prompt，让它生成一份关于 HTTP 协议的 10 题测验，难度递增，每题附带详细的答案解释。

## 创意表达

> i have a worldbuilding premise: near-future Southeast Asia after climate collapse, humanity retreats to arcology cities. write a prompt that produces a 3000-word short story opening.

> 我有一个世界观设定：近未来、气候崩溃后的东南亚、人类退守到架空城市。帮我写个 prompt 让它帮我写一个 3000 字的短篇开头。

> write a prompt that designs 3 distinct character profiles for a cyberpunk RPG campaign. each needs a backstory, a flaw, a secret, and a personal quest.

> 帮我写个 prompt，让它为一个赛博朋克 RPG 团设计 3 个不同的角色档案。每个角色要有背景故事、一个弱点、一个秘密、一个个人任务。

> write a prompt that takes a transcript of a real conversation and adapts it into a short play script. preserve the original emotion but heighten the dramatic tension.

> 帮我写个 prompt，让它根据一段真实对话录音的文字稿，改写成一个小剧场剧本。保留原对话的情绪，但要增强戏剧张力。

> i need a prompt that generates 20 one-sentence story premises in the style of Black Mirror episodes. dark, tech-focused, thought-provoking.

> 帮我写个 prompt，让它生成 20 个一句话故事点子，风格像《黑镜》——黑暗、科技主题、引人深思。

## 个人效率

> my daily tasks are all over the place. write a prompt that takes my to-do list and auto-prioritizes it, giving me a time-blocked schedule.

> 我每天处理的事情太杂了，帮我写个 prompt 让它根据我列的今日待办，自动排优先级，给出一个有时间块的建议日程。

> write a prompt that turns my scattered weekly reflections into a structured weekly review: what went well, what didn't, what I learned, next week's focus.

> 帮我写个 prompt，让它把我零散的每周反思整理成结构化的周回顾：哪些做得好、哪些不好、学到了什么、下周重点。

> i'm tracking 5 projects in parallel, each with messy progress notes. write a prompt that consolidates them into standardized weekly status reports.

> 我在定期跟踪 5 个项目的进展，每次都记一堆散乱的笔记。帮我写个 prompt 让它把原始笔记整理成标准化的项目周报。

> need a prompt that helps me prepare for a difficult conversation with a colleague. role-play the other person's likely reactions and suggest response strategies.

> 帮我写个 prompt，让它帮我准备一次跟同事的困难对话。模拟对方可能的反应，给出应对策略。

## 模糊/不完整输入

> make a prompt for my project

> 帮我写个好用的 prompt

> i have no idea how to describe it, just help me write a prompt that gets the AI to do what i need.

> 不知道怎么描述，反正就是要 AI 帮我做事，你帮我写个 prompt 吧。

## 优化与诊断现有 prompt

> this prompt isn't working — the AI keeps ignoring my format requirements. here it is: "[paste prompt]". help me fix it.

> 我这段 prompt 效果不好，AI 老是忽略我的格式要求。原文是：「[粘贴 prompt]」。帮我改改。

> review this system prompt and tell me what's wrong with it. don't rewrite it yet — just the issues.

> 帮我审一下这段 system prompt，有什么问题？先别急着重写，只要告诉我问题在哪。

> can you make my prompt shorter and clearer? it's too long and rambly, and the AI loses focus halfway through.

> 帮我把这段 prompt 精简一下，太啰嗦了，AI 读到一半就跑偏。

> i wrote a prompt but the AI gives inconsistent results every time. improve it so it's reliable.

> 我写了个 prompt，但 AI 每次给的答案都不稳定。帮我优化，让它稳定可复现。

> here's a rough instruction i drafted — turn it into a proper prompt.

> 这是我草拟的一段指令，帮我把它整理成规范的 prompt。

> no matter how i ask, the AI keeps doing the wrong thing. here's what i told it: "[paste]". how should i phrase it?

> 不管我怎么说，AI 总是做错。我给它的是：「[粘贴]」。我该怎么跟它说才对？
